Personal rclone client

This site describes a private OAuth client for rclone, an open source command line tool for copying files to cloud storage. One person uses the client to copy their own backup files to their own Google Drive on a schedule.

The client is not offered to the public. There is no sign-up, no service to join, and no other user.
