Privacy Policy

Effective 2026-11-05.

Data accessed

The client accesses Google Drive only for the Google account that authorizes it, which is the owner's own account. It lists, uploads and verifies the owner's backup files.

Storage and sharing

OAuth tokens stay on the owner's own computer. The client has no server. No Google user data is collected, sent to the operator, sold, or shared with any third party.

Limited use

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at Google Account permissions.

Contact

Questions can be sent through the GitHub profile that owns this site.
