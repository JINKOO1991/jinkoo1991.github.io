Privacy Policy

Effective 2026-11-14.

Data accessed

The client requests one Google scope, gmail.readonly, only for the Google account that authorizes it, which is the owner's own account. It searches and reads the owner's messages to find travel and booking confirmations and extracts dates, times, flight numbers, booking references and lodging names for the owner.

Storage and sharing

The OAuth refresh token is stored in a private file readable only by the program's service account on the owner's own server. Message contents are processed in memory to answer the owner and are not written to logs. No Google user data is sold, used for advertising, or shared with any third party. Results are shown only to the owner in a private chat.

Limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removal

The owner can revoke access at any time at Google Account permissions. Revoking access stops all reading immediately.
